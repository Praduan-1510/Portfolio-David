# Payment brand marks

`brands.js` is generated by `scripts/fetch-brand-marks.ts`. Run `pnpm brands` to refresh.

## Why these files

A payment sheet is the one screen where a shopper looks for a logo they already trust, so
the marks have to be the real ones, in the real colours. Google Pay is four colours,
Mastercard is red and yellow, Paytm is two blues and HDFC Bank is blue and red —
flattening any of those to a single colour does not simplify the logo, it replaces it.

Each file is fetched through the Commons API by title, then stripped of editor metadata
and namespaced so ids do not collide when several are inlined on one page. Geometry and
colours are otherwise untouched — no recolouring, no reproportioning.

## Licensing

These are registered trademarks of Google, PhonePe, Paytm, HDFC Bank, Amazon, Visa and
Mastercard respectively. They are reproduced here to identify the payment method each one
stands for, which is the purpose a payment mark serves, and this is an unpublished
portfolio prototype that processes no real payments.

A real deployment would take these from each provider’s brand portal under the merchant
agreement, and follow their clear-space, minimum-size and background rules.

## Brandfetch

Brandfetch was the first source tried. Both its Brand API and its logo CDN require an
account: the API answers `401 Unauthorized` without a key and the CDN redirects to its
documentation without a client ID. Add `BRANDFETCH_CLIENT_ID` and this script could pull
from `https://cdn.brandfetch.io/{domain}/w/400?c=$CLIENT_ID` instead.
